# Changelog

All notable changes to Pigeon No One-Shot Headshots are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html):

- **Major** versions can need changes to your configuration or other resources. Read the **Upgrade notes**.
- **Minor** versions add features without breaking existing setups.
- **Patch** versions fix bugs only.

## [Unreleased]

First release.

### Highlights

- No one-shot headshot kills on players
- Every gun, every player
- An export to turn headshots back on for one player

### Added

- GTA's extra headshot damage turned off for every player, applied again on respawn and every `Config.ReapplySeconds`.
- `SetHeadshots` and `HasHeadshots` client exports, to give one player GTA's full headshot damage again.
- GTA's headshot damage put back when the resource stops.
- Update checker from the Pigeon Studios version registry.
